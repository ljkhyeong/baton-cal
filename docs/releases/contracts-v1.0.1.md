# BATON CAL 계약 1.0.1

`1.0.1`은 안정 계약 `1.0.0`의 배포 자산을 보완한 호환 버전이다.

## 변경 사항

- 계약 ZIP 루트에 MIT `LICENSE`를 포함한다.
- ZIP 내부 버전, 파일명과 태그를 `1.0.1`로 맞춘다.
- Gradle이 실제 ZIP의 파일명, 내부 버전과 포함 파일 목록을 검증한다.

스키마, 예시, iCalendar 골든과 PRD의 계약 의미는 `1.0.0`과 같다. 기존 `contracts-v1.0.0` 태그와
자산은 불변 이력으로 유지한다.

BATON은 `contracts-v1.0.1`, `baton-cal-contracts-1.0.1.zip`과 게시된 SHA-256을 새로 고정하고
생산자 계약 테스트를 다시 실행해야 한다.
