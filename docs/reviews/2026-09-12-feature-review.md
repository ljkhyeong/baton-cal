# CAL 후속 기능 검토

- 기준: `f745b6c`, 2026-09-12
- 범위: CAL 소스·기존 테스트·PRD·이전 기능 검토. 추가 요금 없는 개선을 우선한다.

| 항목 | 판단 | 근거와 처리 |
| --- | --- | --- |
| 구독 상태 확인용 HEAD의 본문 조회 제거 | 이번 구현 | 기존 GET 매핑은 HEAD에서도 캘린더 전체를 DB에서 가져온다. 메타데이터만 조회해 상태·갱신 시각·파일 크기를 반환한다. |
| 실제 캘린더 앱의 갱신·취소·이름 표시 확인 | 운영 연결 후 진행 | 앱별 안내와 확인표는 구현돼 있다. 외부에서 접근 가능한 HTTPS와 실제 앱 계정이 필요하다. |
| 대량 일정 수신 시 재구축 횟수 감소 | 운영 목표 확정 후 검토 | 단건 반영마다 전체 피드를 재구축한다. 묶음 수신은 BATON 연동 계약을 바꾸므로 시즌 규모·수신량·복구 목표 시간을 먼저 정한다. |
| 후보 계약의 BATON 정식 적용 | 릴리스 작업으로 분리 | 현재 후보는 `1.1.0-rc.2`다. 공식 ZIP 게시·검증과 BATON의 버전 지정이 필요하다. |

이번 개선은 기존 구독 URL과 GET·304·404 동작을 유지한다. DB 스키마나 외부 서비스를 추가하지 않는다.
HEAD 회귀 테스트는 GET과의 헤더 일치, UTF-8 바이트 길이, 조건부 조회 우선순위, 빈 피드,
잘못된 주소·재발급·해제·이전 세대 토큰 차단을 확인한다. 조회 비용은 본문 조회가 호출되지 않는지 검증하며,
응답 속도 개선율은 별도로 측정하지 않는다. 최종 검증 결과는 [인수인계](../../HANDOFF.md)에 기록한다.
