# CAL 전수검토

- 기준: `9cafd90`(PR #41 병합), 2026-10-30. 수정 브랜치: `codex/full-review-20261030`
- 범위: 핵심 로직·동시성, HTTP 계약, 보안·운영 구성, 테스트·스크립트·빌드, 문서 정합성을 나눠 전체를 읽었다.
  실제 서버·DNS·인증서·캘린더 앱 검증은 포함하지 않는다.
- 판정: 검토 지적을 그대로 받지 않고 코드 실행이나 재현으로 확인했다. 아래 "재현"은 수정 전 코드에서 실패를 직접
  본 항목이다. "판독"은 코드와 문서를 대조해 확인한 항목이다.

## 테스트 보강

항상 참이던 단언 2건을 고치거나 지웠다. 다음을 고정했다.

- 복구: 검증하지 않은 시즌이 남은 완료 거부, 시즌 수가 같고 다이제스트만 다른 완료 거부, 일반 모드의 완료 거부, 형식 오류의
  `400`, 복구 모드 해제 뒤 같은 매니페스트·완료 재시도(OCI 스모크).
- 복구 다이제스트: PRD 규칙으로 따로 계산한 고정값. `f0000000` ID로 UUID 숫자 정렬과 문자열 정렬을 구분한다. BATON 구현의
  문자열 정렬도 소스로 확인했다.
- 알림: 테스트가 없던 4개 규칙의 발생·해제와 수집 공백 뒤 거짓 알림이 없는지.
- HTTP: 무효 토큰의 조건부 요청, `HEAD`의 `304` 기록, 묶음 `413`, 없는 구독 폐기, 이전 세대 구독의 PUT 재요청, UTC 일정의
  시각 변경, 시간대 2개의 `TZID` 정렬, 묶음 수신 지표, 프레임워크 `5xx`.
- 동시성: 폐기가 읽은 뒤 회전이 커밋되는 순서를 고정. 기존 테스트는 실행마다 경합 결과가 달랐다.
- 시간 의존: UTC 자정 경계의 간헐 실패 제거, TLS 교체 대기 여유 확보.

## 수정하지 않은 지적

| 지적 | 판단 | 근거 |
| --- | --- | --- |
| `If-None-Match: *`가 `200`, `If-Unmodified-Since`가 `412` | PRD에 범위 명시 | 안전한 방향으로 동작하고 RFC 9110은 GET의 `412`를 허용한다. Nginx는 뒤 헤더를 전달하지 않는다. Spring 조건부 처리를 다시 구현할 근거가 없다 |
| `//calendars/...`의 JSON `404` | 유지 | 프록시 경유로 도달하지 않고 토큰이 응답·관측에 남지 않는다 |
| 진행 중 연결 끊김의 `500` | 유지 | BATON은 `500`도 재전송한다. `503` 목록은 연결 획득 실패까지다 |
| `CalHttpServerErrors`의 첫 표본 | 유지 | 지속되는 오류는 다음 표본부터 잡히고 임계값이 있다. 한 수집 주기 안에 끝나는 일회성 급증은 알림 대상이 아니다 |
| `or vector(0)` 기록 규칙 제안 | 미채택 | 수집 공백 뒤 누적값 복귀를 카운터 리셋으로 계산해 거짓 알림을 낸다 |
| 전체 TZID를 JVM과 대조하는 상시 테스트 | 미채택 | JDK 데이터가 바뀌면 코드와 무관하게 실패한다. 1970~2037년을 한 번 대조했고 대표 시각을 고정값으로 남겼다 |
| Compose 네트워크 분리·컨테이너 권한 축소·TLS 강화·DB 계정 분리 | 보류 | 운영 대상은 k3s이고 Compose는 통합 검증용이다. k3s 구성 작업에서 정한다. [남은 작업](../../HANDOFF.md#남은-작업) |
| CI 게시 작업 분리, Alertmanager 자기 감시 | 보류 | 현재 위험이 낮고 운영 연결 뒤 필요성을 판단한다 |
| 복구 완료의 시즌별 N+1 조회 | 보류 | 시즌 수가 드러나기 전이며 완료는 복구 때만 실행한다 |
| Stop 훅의 반복 차단 | 확인 필요 | 실제 Codex 세션 동작을 확인하지 못했다 |

## 측정과 교차 검증

- 공개 조회의 최근 조회일 기록 영향은 측정 편차 안이었다. [성능 기준](../performance-baseline.md#2026-10-30-최근-조회일-기록과-ical4j-440-재측정)
- BATON `main`의 교차 서비스 테스트 5개가 임시 호환 파일로 통과했다. 스크립트는 삭제된 `compose.smoke.yml`과
  `1.1.0-rc.2`만 허용해 저장소 그대로는 시작하지 못한다. BATON 쪽 수정이 남아 있다.
